      Project Entity Data Dictionary

      Complete structural reference of all 16 persistent data models and schemas within the ZENO parking ecosystem. Click any row to jump and highlight in diagram.

      Class Name Collection / Table Stereotype Primary Key Foreign Keys System Responsibility
      Report reports Mongoose Model _id (ObjectId) generatedBy, buildingId System-wide and facility-specific analytical reports (revenue, occupancy, booking volume) exportable to CSV and PDF formats.
      Building buildings Mongoose Model _id (ObjectId) ownerId Physical facility representation containing address, total floor count, geolocation coordinates, and owner linkage.
      SlotBlackout slotblackouts Mongoose Model _id (ObjectId) slot, owner Time window blackout reservations created by owners for maintenance, private events, or scheduled closures.
      Notification notifications Mongoose Model _id (ObjectId) userId Automated user alerts (booking confirmations, reminders, overstay alerts, payment receipts) with in-app & email dispatch.
      Slot parkingslots Mongoose Model _id (ObjectId) building, owner Individual parking space bay classified by type (standard, compact, large, EV), floor level, dimensions, and baseline rate.
      PricingRule pricingrules Mongoose Model _id (ObjectId) owner, building Configurable dynamic pricing rule engine with surge/discount percentages, demand thresholds, time windows, and day filters.
      User users Mongoose Model _id (ObjectId) None Central identity entity for all platform actors supporting role-based access control (Admin, Owner, Renter).
      Booking bookings Mongoose Model _id (ObjectId) renterId, slotId, vehicleId, seriesId Central reservation transaction handling lifecycle states, slot locking, pricing snapshots, and automatic expiration.
      CheckInOut checkinouts Mongoose Model _id (ObjectId) bookingId Physical vehicle ingress and egress timestamp tracking for booked slots, activating live status and detecting overstays.
      OverstayPenalty overstaypenalties Mongoose Model _id (ObjectId) bookingId Enforced monetary penalty calculated automatically when actual physical check-out exceeds the reserved booking end time.
      Vehicle vehicles Mongoose Model _id (ObjectId) userId, renterId Renter-registered vehicle profiles containing plate number, category, and size class for parking validation.
      BookingSeries bookingseries Mongoose Model _id (ObjectId) renterId, slotId, vehicleId Recurring booking schedule container generating repeated daily/weekly booking occurrences across a designated date window.
      Payment payments Feature Schema _id (ObjectId) bookingId, renterId Financial transaction settlement record storing Stripe checkout session, payment intent tokens, amount, and currency.
      Review reviews Feature Schema _id (ObjectId) bookingId, renterId Post-completion quality evaluation with 0.25-precision star ratings (0.00-5.00), written feedback, and owner response.
      Subscription subscriptions Feature Schema _id (ObjectId) renterId Recurring monthly parking hour allotment plans (Basic 20h, Pro 50h, Premium 100h) integrated with Stripe subscriptions.
      Invoice invoices Feature Schema _id (ObjectId) bookingId, renterId, paymentId Official serialized fiscal invoice document (e.g. INV-2026-0001) linked to booking and payment records.
